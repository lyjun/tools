# x-design-dialogue

規格沒寫、或寫得不夠精準的那幾點，答案在使用者腦中，不在任何文件裡。這支 skill 管的是怎麼把
那幾點問出來、怎麼提方案、怎麼確認同意——讀 code 與查規格照常做，它們回答不了的才進這裡。

## 1. 先分類，並且說出來

第一個問題之前，先判斷這件事屬於哪一類，把判斷寫在回覆裡（「這看起來是小改，我在這裡給一段
設計，不另寫文件」），讓使用者可以推翻。

| 類別 | 判準 | 交什麼 | 門檻 |
|---|---|---|---|
| 探測 | 問題是「做不做得到」，產出是一個答案，不是要留下的 code | 2–3 句：要回答的問題、打算怎麼試 | 使用者點頭才試；試出來的東西標「拋棄式」 |
| 小改 | 要改的流程**已經在 repo 裡讀得到** | 對話裡一段短設計：做法、動到的檔、怎麼驗 | 使用者明說同意才動手 |
| 結構性 | 新的子系統、改別人依賴的介面、跨 repo、沒有既有流程可改 | 意圖 → 2–3 個方案 → 分段設計，每段確認 → 結論寫進檔案 | 每段都要同意；最後那份檔案也要同意 |

拿不準時選較重的那類。類別只往上調不往下調：做到一半發現比想的複雜，停下來說明、改用較重
那類的流程；不因為「快做完了」而不調。

「小改」看的是 repo，不是我熟不熟這類東西：要改的流程讀不到，就不是小改。

## 2. 先寫回我的理解

把聽到的意圖、成功長什麼樣、限制條件寫成幾句話，**分開「你說的」與「我推的」**，請使用者修正。
需求本身已經講清楚這些時，照著寫回一次就好，不重問。

分開兩者是因為「我推的」那幾句最容易在之後被當成使用者說過的話，以那個身分進到設計裡。

## 3. 問題一次列完

把**會改變做法**的未決點全部列出來，一次問完，不要一輪冒一題。問法：

- 能用選擇題就用選擇題，每題附 2–3 個選項、我推哪一個、一句判準（可查的事實，不是偏好）
- 一次最多 4 題（AskUserQuestion 的上限）；超過時先講總共幾題，再分批
- 答案不會改變做法的點不問，選預設值並在清單裡寫明「沿用預設 + 一句理由」

一次列完而不是一題一題問，是因為零碎地問會讓對方判斷不了還剩幾題，每輪都像多開一個戰場。

**題目之間有依賴時分輪問**（上面「一次問完」的唯一例外，4 題上限照舊）。每一輪問的是「依賴的題目
都已有答案」的**全部**題目；依賴本輪另一題的，留到下一輪。延後一題要寫出依據：**前一題的哪個答案，
會讓這題的哪個選項消失或改變**——寫不出這句，這題就屬於這一輪。兩題互相依賴時併成一題，選項只列
可行的組合，最多 3 個。每輪開頭寫：目前已知幾題（答案可能再長出新題）、這輪問哪幾題、哪幾題延後以及各自的依據。

依賴不分輪的代價是兩頭的：下一輪的選項得先猜這一輪的答案，猜錯了整題作廢；硬塞進同一輪，使用者
得自己排出先答哪題。

## 4. 提方案

結構性的那類，提 2–3 個方案。每個方案寫：做法、動到哪些地方、代價、什麼條件下它會是錯的選擇。
最後推一個，理由要是可查的事實。只想得到一個方案時，明寫「只有這條，因為 …」。

## 5. 同意是門檻

設計交出去就停，等使用者明說同意。同一則回覆裡交設計又開始動手，等於跳過門檻——門檻是那句
同意，不是設計的長度。

同意只涵蓋**當下呈現的那一段**。同意了方向，不代表同意了還沒寫出來的細節；同意了探測，
不代表同意了接下來把它做成正式功能。

等待同意期間，讀 code、跑唯讀查詢可以；改檔、建分支、裝套件不行。

## 6. 產出：封閉清單

談完交一份清單，三類分開，每條重述它在講什麼，不只給編號：

- **已決定**：決定的內容，加上來源——`使用者 口頭（YYYY-MM-DD）`，或 `沿用預設：<理由>，使用者未反對`
- **等你決定**：還沒有答案的點，每點寫誰有權決定
- **擺著不動**：這次刻意不處理的點，逐項點名

來源一定要寫：下一個 session 讀到這份清單時，要分得出哪些是使用者拍板、哪些是我自己定的。
呼叫端指定了寫到哪個檔案就寫進那裡；沒有指定就寫在對話裡。

## 常見的自我豁免

| 心裡想的 | 為什麼不行 |
|---|---|
| 「這很簡單，不用設計」 | 小改的設計可以只有兩句，但那兩句與一句同意都要有 |
| 「標成小改就能少一步」 | 為了少做事而挑類別，本身就是拿不準——選較重的那類 |
| 「設計很明顯，邊講邊開始做」 | 門檻是同意，不是設計長度。交出去，停 |
| 「他同意方向了，細節我來定」 | 同意只涵蓋呈現過的那一段 |
| 「做到一半變複雜了，但快好了」 | 停下說明，往上調類別 |
| 「先問一題，其他的之後再說」 | 會改變做法的點一次列完；延後一題要寫得出前一題的哪個答案會改掉它的哪個選項，寫不出就屬於這一輪 |
